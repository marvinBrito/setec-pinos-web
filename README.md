# SETEC PINO'S — Sitio web

Página de servicios de aire acondicionado (instalación, traslado, mantenimiento, reparación y carga de gas).

Sitio estático: HTML + CSS + JS, sin build. Se despliega tal cual en Vercel.

- `index.html` — contenido
- `css/styles.css` — estilos
- `js/main.js` — menú, galería y cotizador por WhatsApp
- `img/` — fotos de trabajos y logo

El WhatsApp (+593 98 980 7375) está en `index.html` y en `js/main.js` (constante `PHONE`).

Despliegue: Vercel (proyecto estático, Framework Preset `Other`, sin build).
